# Architecture Decision Records (ADR)

We document significant technical decisions here before implementing them.

## Format

Each ADR includes:

1. **Context** — what problem we are solving
2. **Decision** — what we chose
3. **Alternatives considered** — other options and why we rejected them
4. **Consequences** — tradeoffs, risks, follow-ups
